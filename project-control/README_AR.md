# نظام المركزية الكامل لمشروع VVIP TIGER

هذا الحزمة تحول ملفات Word المعتمدة إلى مصدر عمل منظم وقابل للبحث والاستيراد داخل مركز تحكم المشروع.

## ما تم تنفيذه

- حفظ 3 ملفات مصدر كاملة مع نسخ Word ونص Markdown وJSON خام وبصمة SHA-256.
- استخراج 23 مرحلة و70 مهمة مرقمة.
- استخراج 553 خطوة للمبرمج، و420 عنصر بناء، و280 متطلب أمن وخصوصية، و420 اختبار QA، و420 معيار/مخرج قبول.
- إنشاء سجل اعتمادات بين المهام بعدد 112 علاقة موصى بها.
- إنشاء قاعدة بيانات `project_control` وSeed جاهز للمراجعة على Development/Staging.
- إنشاء لوحة تحكم HTML عربية تعمل محليًا، تحفظ تغييرات الحالة في LocalStorage وتصدرها JSON.
- إنشاء سجل استراتيجي يمنع حذف أي فكرة أو مهمة مؤجلة.

## ترتيب الاستخدام

1. افتح `dashboard/VVIP_TIGER_Project_Control_Center_AR.html` للمراجعة الفورية.
2. راجع `data/master_task_registry.csv` و`data/tasks.json`.
3. شغّل `database/001_project_control_schema.sql` على Development فقط.
4. راجع ثم شغّل `database/002_project_control_seed.sql` على Development/Staging.
5. اربط واجهة مركز المالك بخدمة Backend تقرأ من schema `project_control`؛ لا تستخدم Service Role في المتصفح.
6. بعد قبول QA والأمن وخطة التراجع، انقل التغييرات عبر Pull Request رسمي.

## قاعدة عدم الضياع

لا يتم حذف أي عنصر من المصادر. العناصر غير المطلوبة في الإصدار الحالي تنقل إلى `strategic_backlog.csv` أو تبقى في `strategic_archive.json` مع مصدرها وبصمتها.

## ملاحظة أمان

هذه الحزمة لم تطبق أي SQL على Production ولم تعدل مستودع GitHub. هي حزمة تنفيذ واستيراد جاهزة للمراجعة الآمنة.
