# مواصفة السعة والأداء العالمي

## نطاق السعة
الهدف التجاري هو تجاوز 4,000,000 مستخدم مسجل في السنة الأولى. لا يفترض أن الجميع متزامنون. تعتمد السعة الإنتاجية على Beta telemetry مع هامش لا يقل عن ضعفي الذروة المرصودة، وتختبر على درجات 10 آلاف و25 ألفًا و50 ألف مستخدم افتراضي متزامن للرحلات المحددة.

## SLO الأساسية
- توفر شهري للرحلات الأساسية: 99.95%.
- P95 لقراءة API: 500ms، والكتابة: 800ms، والبحث: 700ms داخل طبقة الخدمة، مع قياس منفصل لزمن الشبكة.
- Core Web Vitals عند P75: LCP ≤ 2.5s، INP ≤ 200ms، CLS ≤ 0.1.
- أخطاء الخادم أقل من 0.5% في نافذة القياس.
- RPO لقاعدة البيانات ≤ 5 دقائق، RTO للخدمة الأساسية ≤ 60 دقيقة.
- على ملف شبكة مقيدة: أول محتوى مفيد خلال 5 ثوان عند P75 للرحلات العامة.

## تصميم الأداء
- CDN للأصول العامة والصور المشتقة، Cache-Control واضح، filenames موقعة بالإصدار.
- Pagination cursor-based؛ لا تحميل كامل القوائم.
- Connection pooling للخدمات الخادمية، وعدم فتح اتصال لكل طلب.
- فهارس حسب الاستعلامات المقاسة، ومراقبة الاستعلامات البطيئة.
- Background queues للصور والإشعارات والفهرسة، مع idempotency وdead-letter handling.
- Load shedding وrate limiting وfeature degradation بدل الانهيار الكامل.

## بوابة 4 ملايين
لا يعتمد رقم 4 ملايين كشعار. قبل Global GA يجب إثبات: حمل البحث، إنشاء الإعلان، قراءة التفاصيل، الدخول، الرسائل، الإشعارات، وفشل مورد خارجي؛ مع تكلفة متوقعة وحدود وتنبيهات.
