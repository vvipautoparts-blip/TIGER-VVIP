# تسوية الخارطة القديمة مع الخارطة العالمية

خارطة `P00–P34` تبقى سجلًا تاريخيًا، وخارطة `G00–G22` هي خارطة التنفيذ العالمية المركزية. ملف `data/legacy_phase_mapping.csv` يحدد الارتباط. لا يعني اكتمال شاشة أو وثيقة أن الوحدة العالمية مكتملة؛ حالة G تعتمد على Runtime وSecurity وPerformance evidence.
