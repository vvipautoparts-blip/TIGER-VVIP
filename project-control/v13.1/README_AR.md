# حزمة السلطة التنفيذية V13.1

هذه الحزمة هي المصدر التنفيذي الداخلي لقرارات VVIP TIGER V13.1 بعد قرار المالك النهائي بتاريخ 2026-08-05 وآخر تعديلاته.

## ترتيب السلطة

1. `contracts/owner_constitution.json`.
2. اختبارات V13.1 والمدقق Fail-Closed.
3. `contracts/conflict_registry.json` و`authority-manifest.json`.
4. عقود الدول والقطاعات والوظائف.
5. الكود والواجهات.
6. الوثائق التاريخية والتوضيحية.

## القواعد الثابتة

- سبع صور لكل إعلان، بلا زيادة مدفوعة.
- الفيديو غير مفعّل في الإصدار الحالي.
- لا رقم ظهور عالمي ثابت؛ الكمية والسعر داخل ختم الدولة فقط.
- الدردشة والتوصيل والوساطة متاحة لجميع المستخدمين دون موافقة المالك أو الشركاء.
- زر التحويل إلى واتساب متاح لجميع المستخدمين دون موافقة.
- واتساب ليس جزءًا من نظام المراسلة في المنصة؛ الزر يفتح تطبيق واتساب المثبّت على جهاز المستخدم عبر رابط خارجي فقط.
- المنصة لا ترسل رسائل واتساب ولا تستقبلها ولا تقرأها ولا تخزنها ولا تدير حساب واتساب.
- لا تغيير مباشر على `main`.
- لا إطلاق دولة أو حركة مالية بلا بواباتها المعتمدة.

## التحقق

يشغّل المدقق:

```bash
node project-control/scripts/validate_v13_1_authority.mjs
```

ويفشل عند رجوع حد الصور إلى غير 7، أو إدخال رقم ظهور عالمي، أو تقييد القدرات العامة بالموافقات، أو تحويل واتساب إلى مراسلة داخلية، أو إضافة شرط موافقة، أو كسر بصمات SHA-256.
