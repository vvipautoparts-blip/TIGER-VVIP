Data Deletion Instructions - Vvip Autoparts

If you want your data deleted, submit a deletion request using one of the following methods:

1. From inside the app

Go to Account Settings, choose Delete Account, and follow the steps.

2. By email

  • Send your request to: vvipautoparts@gmail.com
  • Subject: Data Deletion Request
  • Include basic account identifiers (registered email or phone number).

Request handling

  • We verify requester identity before processing.
  • Requests are processed within a reasonable timeframe depending on data volume and legal requirements.

What is deleted

  • Profile data and operational data associated with the account.
  • We may retain a minimal set of data if legally or security required.

Last updated: 2026-07-01
