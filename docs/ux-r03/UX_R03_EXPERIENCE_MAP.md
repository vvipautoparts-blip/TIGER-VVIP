# UX-R03 Experience Map

User path: Authentication via Clerk -> Unified Home -> Marketplace or Search -> In-place listing details -> Public or Private profile -> Create Listing -> Posting authorization -> Image pipeline -> Private one-to-one communication -> Tiger Care.

Operations path: User action -> Operations queue -> Authorized employee -> Scope-limited action -> Audit log -> Escalation when required.

The UX-R03 showcase connects these paths visually only. It contains no backend integration, data transport, or authorization enforcement.
