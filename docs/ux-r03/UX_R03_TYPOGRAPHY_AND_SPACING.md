# UX-R03 Typography And Spacing

The Arabic-first reference stack is `Tahoma, "Noto Kufi Arabic", sans-serif`. The scale covers display, page, section, card, body, small, caption, button, and numeric metric text.

Spacing steps are 4, 8, 12, 16, 20, 24, 32, and 40 pixels. Cards use 8px as the normal radius, controls have a minimum 44px hit area, media uses 4:3, and text must wrap rather than silently clip important information.

Tokens are preview-only documentation; implementation adoption needs a separately approved package.
