# UX-R03 Color System

## Reference Palette

- Navy is reserved for identity, headings, and structural navigation.
- Blue is the only daily primary-action color.
- Gold is a limited premium emphasis, never a default action color.
- Green, warning amber, and red communicate success, review, and danger with accompanying text or icons.
- Light page surfaces and white cards are the reference direction for this preview.

The canonical values are in `design-system-preview/design-tokens.css`. This is a visual reference, not a production style migration.
