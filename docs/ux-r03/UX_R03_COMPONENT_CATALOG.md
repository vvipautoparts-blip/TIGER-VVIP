# UX-R03 Component Catalog

The local library catalogs navigation, actions, filters, form controls, listing/profile/employee/ticket/moderation cards, status feedback, tables, timeline/audit/notification items, and image workflow tiles.

Each catalog item records its purpose and expected visible states. Interactive specimens cover the primary action hierarchy, sector filters, fields, dialog/sheet, status feedback, cards, tables, and responsive alternatives.

Catalog membership does not make any component a production component or grant authorization behavior.
