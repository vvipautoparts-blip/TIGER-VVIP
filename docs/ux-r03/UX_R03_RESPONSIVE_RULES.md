# UX-R03 Responsive Rules

- Desktop: persistent reference index, three-column examples, internally scrollable tables.
- Tablet: flexible grids and preserved control targets.
- Mobile: one-column catalog, compact header with an index drawer, no global horizontal scroll, and table cards in place of dense data tables.
- Dialogs become bottom sheets on narrow screens and include the safe-area inset.
- Reduced motion disables nonessential animation.

These rules are validated in the local UX-R03 preview only.
