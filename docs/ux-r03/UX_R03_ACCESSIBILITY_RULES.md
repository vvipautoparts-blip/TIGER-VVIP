# UX-R03 Accessibility Rules

The previews use Arabic RTL documents, skip links, semantic landmarks and headings, associated field labels, visible focus styles, keyboard-operable chips and dialogs, minimum touch targets, and reduced-motion support.

Status is conveyed with readable text and symbols as well as color. Sensitive actions have text labels, and dialogs can be closed with Escape or the explicit close control.

Accessibility implementation is a frontend reference. It does not replace a full accessibility audit before production use.
