# مواصفة تجربة البحث العالمية

## النتيجة المطلوبة
بحث سريع ومفهوم يشبه في سهولة الاستخدام أسواق الإعلانات الكبرى دون نسخ تصميمها أو كودها. يبدأ المستخدم بعبارة أو فئة وموقع، ثم يضيق النتائج بفلاتر ديناميكية.

## رحلة المستخدم
1. شريط بحث عالمي يدعم العربية والإنجليزية واللغات المعتمدة.
2. اختيار الدولة/المدينة مع إمكانية استخدام موقع تقريبي بموافقة المستخدم.
3. اقتراحات فورية: عبارات، فئات، علامات، مواقع وعمليات بحث سابقة.
4. صفحة نتائج تعرض عدد النتائج، الفرز، فلاتر سريعة، وفلاتر إضافية في Bottom Sheet على الهاتف.
5. فلاتر أساسية: الفئة، الموقع، السعر، العملة، الحالة، الصور/الفيديو، المستخدم أو المنشأة الموثقة، التوصيل، التقييم والتاريخ.
6. فرز: الأكثر صلة، الأحدث، السعر، الأقرب. الإعلان المدفوع يوسم بوضوح ولا يتغلب على الأمان أو الصلة الدنيا.
7. حفظ البحث والتنبيه عند وجود نتائج جديدة.
8. عند صفر نتائج: تصحيح إملائي، توسيع الموقع/السعر، اقتراح فئة، وإزالة فلتر واحد بإذن المستخدم.

## معالجة اللغة
- توحيد الألف والهمزات والياء/الألف المقصورة والتاء المربوطة مع الاحتفاظ بالنص الأصلي.
- تجاهل التشكيل في المطابقة، ودعم المرادفات والأسماء التجارية والكتابة العربية/اللاتينية عند توفر قاموس معتمد.
- لا تغير الخوارزمية معنى الاستعلام، وتعرض للمستخدم أي تصحيح تم تطبيقه.

## خط أنابيب البحث
`normalize -> parse intent -> apply country/category policy -> retrieve candidates -> filter authorization -> rank -> deduplicate -> disclose promotions -> return facets`

## الإنترنت الضعيف
- أول 20 نتيجة فقط، payload مضغوط، إلغاء الطلب السابق عند كتابة جديدة، Cache قصير للبحث العام، وصور مصغرة lazy-loaded.
- عرض Skeleton خفيف ثم النص والسعر قبل الصور.
- الاحتفاظ بآخر عمليات بحث ونتائج عامة محدودة محليًا، دون بيانات خاصة.

## القياس
تقاس: زمن الاستجابة، CTR، zero-result rate، تعديل الاستعلام، استخدام الفلاتر، حفظ البحث، البلاغات، والنتائج غير ذات الصلة. لا يستخدم التفاعل لتمييز غير شفاف أو مخالف للخصوصية.
