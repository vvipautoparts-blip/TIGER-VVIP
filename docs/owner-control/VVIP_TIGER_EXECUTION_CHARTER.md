## البدائل المسموحة

Safe fallback يعني **سلوك اعتمادية آمنًا ومتوافقًا مع السلطة الحالية فقط**، مثل retry bounded أو degraded read-only state. لا يعني إعادة مسار منتج قديم أو سلطة قديمة أو runtime محذوف.

عند الحاجة يحدد التغيير:

- Primary Path.
- Safe failure/degraded behavior.
- Retry Policy.
- User Message.
- Logging Policy.
- Rollback/Cancel عند انطباقه.
