# VVIP TIGER — القانون والخصوصية والاستمرارية والمراقبة

## 1. المستندات القانونية المطلوبة

- شروط الاستخدام.
- سياسة الخصوصية.
- سياسة الإعلانات والمحتوى.
- قواعد المجتمع.
- سياسة الحسابات والتعطيل والحذف.
- سياسة البلاغات والاعتراض.
- سياسة ملفات الارتباط عند الحاجة.
- إخلاء مسؤولية الصفقات.
- سياسة الاشتراكات والاسترجاع عند تفعيل الدفع.
- سياسة حقوق الصور والمحتوى.
- سياسة الأطفال والسن القانوني عند الحاجة.

## 2. حقوق المستخدم والبيانات

يجب تحديد:

- البيانات التي نجمعها.
- سبب جمعها.
- مدة الاحتفاظ بها.
- من يستطيع الوصول إليها.
- حق التصحيح.
- حق حذف الحساب.
- حق تنزيل البيانات.
- التعامل مع النسخ الاحتياطية بعد الحذف.
- الاحتفاظ بالسجلات الأمنية.
- الاحتفاظ بالمحادثات.
- الاحتفاظ بصور الإعلانات.
- التعامل مع الطلبات القانونية.

المدد التفصيلية تحتاج اعتمادًا قانونيًا وإداريًا قبل الإطلاق.

## 3. البيئات

يجب فصل:

- Development.
- Staging.
- Production.

القواعد:

- لا اختبار عشوائي على Production.
- أسرار مستقلة لكل بيئة.
- بيانات اختبار غير حقيقية.
- Feature Flags للميزات الجديدة.
- Rollout تدريجي.
- Rollback واضح.
- Version لكل إطلاق.

## 4. النسخ الاحتياطي والتعافي

- نسخ احتياطي مجدول.
- اختبار استعادة فعلي.
- تحديد RPO وRTO لاحقًا.
- خطة تعطل Supabase.
- خطة تعطل Clerk.
- خطة تعطل التخزين.
- خطة اختراق أو تسريب.
- سجل حوادث.
- مسؤول استجابة.
- قوالب تواصل للمستخدمين عند الحوادث.

## 5. مقاومة الإساءة والهجمات

- Rate Limits.
- حماية Bots.
- حماية تسجيل الدخول.
- حماية النماذج من Spam.
- حدود الرسائل.
- حدود الدعوات.
- حدود البلاغات.
- إدارة الأجهزة والجلسات.
- التحقق من الروابط الخارجية.
- منع الرفع الخطر.
- منع التكرار الآلي.
- كشف الأنماط المشبوهة.

## 6. المراقبة

يجب قياس:

- أخطاء JavaScript.
- أخطاء الخادم.
- زمن تحميل الصفحات.
- الصفحات الأبطأ.
- نجاح تسجيل الدخول.
- نجاح تحميل الملف.
- نجاح البحث.
- نجاح إنشاء الإعلان.
- نجاح رفع الصور.
- نجاح التواصل.
- فشل الخدمات الخارجية.
- ارتفاع البلاغات أو الإساءة.

## 7. الخصوصية في المراقبة

- لا Tokens.
- لا JWT.
- لا كلمات مرور.
- لا أسرار.
- لا محتوى محادثات كامل دون ضرورة قانونية وأمنية.
- لا جمع بيانات أكثر من الحاجة.
- إخفاء البيانات الحساسة.
- صلاحيات محدودة للوصول إلى السجلات.

## 8. المراجعة الأمنية الأخيرة

قبل الإطلاق العام يجب تنفيذ مراجعة مستقلة أخيرة تشمل:

- Clerk.
- Supabase.
- RLS.
- RPC.
- Storage.
- الأسرار.
- الحسابات الإدارية.
- الحذف.
- النسخ الاحتياطي.
- التسجيل والمراقبة.
- القانون والخصوصية.
