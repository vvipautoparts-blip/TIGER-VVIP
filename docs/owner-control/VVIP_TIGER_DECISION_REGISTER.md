# قرارات واجهة حُسمت لمنع التعارض

## بطاقة الإعلان

المحتوى الأساسي البارز:

- الصورة.
- الاسم.
- السعر.

المعلومات الثانوية الخفيفة عند الحاجة:

- القطاع أو التصنيف.
- المدينة أو المنطقة.
- الحالة أو الشارة.

لا تتحول البطاقة إلى صفحة تفاصيل مصغرة.

## التنقل

نظام موحد يشمل:

- الرئيسية.
- الملف العام.
- الملف الخاص.
- إنشاء الإعلان.
- الإشعارات.
- القائمة والإعدادات.
- تسجيل الخروج.
- اكتشاف المستخدم الحالي.
- أزرار مالك المحتوى.
- أزرار الزائر.

## تسجيل الخروج

ينهي الجلسة فقط، ولا يحذف الحساب أو البيانات.

## أول دخول

يختار المستخدم نوع الحساب، ويحدد الاختيار:

- الواجهة.
- الصلاحيات.
- حدود النشر.
- التحقق.
- ظهور الميزات.
