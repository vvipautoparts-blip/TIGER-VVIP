# TIGER 9D — Temporary Operating Codename Authority

**الحالة:** `CURRENT_ONLY / TEMPORARY OPERATING CODENAME`

**تاريخ اعتماد المالك:** 2026-08-21

## 1. قرار المالك

يعتمد المالك اسم **TIGER 9D** بوصفه **اسم تشغيل مؤقت** تبدأ تحته إجراءات التطوير والتوثيق والتنظيم الحالية إلى أن يتم اختيار الاسم العالمي النهائي بعد استكمال البحث والفحص القانوني والتجاري.

هذا القرار لا يحوّل TIGER 9D إلى علامة نهائية ولا يمنع تغييره لاحقًا.

## 2. النطاق المسموح

يسمح باستخدام **TIGER 9D** في:

- مراجع المالك الحالية؛
- وثائق التطوير والهندسة؛
- أسماء المبادرات والمراحل التشغيلية الجديدة عندما يلزم اسم مرجعي؛
- العناوين والعرض المؤقت داخل بيئات التطوير أو المعاينة عندما يكون ذلك آمنًا وغير مضلل.

## 3. ما لا يتغير بهذا القرار

لا يجيز هذا القرار وحده:

- إعادة تسمية مستودع `TIGER-VVIP`؛
- تغيير أسماء الجداول أو مخططات قاعدة البيانات أو معرفات الكيانات المستقرة؛
- تغيير عقود API أو مفاتيح التكامل أو أسماء الأسرار أو متغيرات البيئة لمجرد العلامة؛
- تغيير الدومينات أو DNS أو الشهادات؛
- تسجيل علامة تجارية أو الادعاء بملكية قانونية نهائية للاسم؛
- تغيير `main` أو Production أو Staging أو بيانات مستخدمين حقيقية؛
- تنفيذ Rename شامل أو destructive migration.

## 4. قاعدة فصل العلامة عن البنية

يجب إبقاء الاسم التشغيلي في طبقة **Branding / Presentation / Documentation** قدر الإمكان. لا يجوز إدخال `TIGER9D` كمعرّف أعمال دائم في قواعد البيانات أو عقود التكامل إذا كان الهدف الوحيد هو الاسم المؤقت.

أي مكوّن يحتاج معرّفًا تقنيًا دائمًا يستخدم اسمًا وظيفيًا محايدًا لا يعتمد على العلامة المؤقتة، ما لم توجد ضرورة هندسية موثقة.

## 5. شرط الاستبدال

عند اعتماد الاسم العالمي النهائي لاحقًا:

1. يُنشأ قرار مالك صريح بالاسم النهائي؛
2. يُصنف TIGER 9D كـ `RETIRED_TEMPORARY_CODENAME / HISTORICAL_ONLY`؛
3. تُستبدل طبقة العرض والتوثيق والهوية البصرية بصورة منظمة؛
4. لا تُغيّر المعرفات التقنية المستقرة بلا حاجة؛
5. أي تغيير دومين أو اسم حزمة أو تكامل يخضع لخطة انتقال واختبارات مستقلة.

## 6. علاقة القرار بالعمل الحالي

**TIGER 9D** هو الاسم المرجعي المؤقت الذي يمكن أن تستمر تحته إجراءات المشروع الحالية دون انتظار اكتمال البحث عن العلامة النهائية.

هذا القرار **لا يغيّر ترتيب البوابات، ولا يلغي اختبارات Quality Gate، ولا يمنح إذنًا بالدمج أو النشر أو لمس Production**.

## 7. العبارة الملزمة

> **TIGER 9D اسم تشغيل مؤقت قابل للاستبدال لاحقًا. نستخدمه لتقدم العمل الآن، ونحمي البنية التقنية من الارتباط بعلامة لم تُعتمد نهائيًا بعد.**
