# Incident Response

## Immediate Actions
- Stop new write intents.
- Isolate affected scope.
- Preserve evidence before mitigation.

## Investigation
- Build timeline from logs and immutable records.
- Perform root-cause analysis.
- Distinguish trigger, blast radius, and control gaps.

## Recovery
- Use validated backup and verified restore path.
- Execute documented rollback when required.
- Verify integrity before reopening writes.

## Post-Incident
- Rotate keys where exposure risk exists.
- Document corrective and preventive actions.
- Keep audit trail complete.
