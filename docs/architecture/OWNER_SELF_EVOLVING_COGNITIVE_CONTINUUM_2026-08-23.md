## Canonical model

**Self-Evolving Cognitive Continuum with Constitutional Genome**

Canonical phrase:

> **THE DEAL STOPS. THE MIND EVOLVES.**

The external commercial relationship still terminates at `CONTACT -> HANDOFF`. TIGER does not continue into negotiation, agreement, final price, external payment, settlement, fulfillment, completion, brokerage or transaction-value commission. The internal cognitive system may continue improving from lawful in-platform signals without observing the external deal after handoff.

## 1. Permanent mind, evolving knowledge

The cognitive system is persistent, but its knowledge is not treated as permanently correct. It must support understanding, memory, connection, prediction, imagination, questioning, creation, critique, verification, consolidation, selective forgetting and governed evolution.

The design rejects `SAVE EVERYTHING FOREVER`.

## 2. Constitutional Genome

A stable constitutional genome constrains all cognitive evolution. It protects at least:

- privacy;
- security;
- owner authority;
- zero-brokerage / discovery-only boundaries;
- terminal CONTACT HANDOFF;
- separation of organic relevance from paid delivery;
- applicable policy and lawful jurisdiction adapters;
- user rights and truthful system behavior.

The cognitive system may improve around this genome, but it cannot silently rewrite or bypass the genome itself.

## 3. Selective living memory

Memory is governed rather than accumulated blindly. The system may store, connect, compress, update, recall, consolidate, decay and forget according to purpose, evidence, utility, freshness, privacy and policy.

Knowledge should distinguish classes such as:

`FACT | OBSERVATION | EXPERIENCE | HYPOTHESIS | BELIEF | PREDICTION | OPINION | UNKNOWN`

A knowledge item should carry a truth envelope where applicable:

`content + provenance + confidence + freshness + valid_from + valid_until + privacy_class + utility + contradiction_score + decay_rate + evidence`

## 4. Multi-dimensional cognitive memory

The internal memory fabric may combine semantic, temporal, causal, entity, procedural and policy relationships. This extends the existing Semantic World Graph rather than replacing it.

## 5. Cognitive Half-Life and real forgetting

Knowledge may decay, be superseded, corrected, compressed or purged. Forgetting must be real where required: deletion obligations propagate through raw memory, summaries, indexes, embeddings, graph links, caches and derived beliefs where technically applicable.

Persistent intelligence does not mean persistent surveillance.

## 6. Living World Model and Selective Foresight

The cognitive system may maintain a living representation of current state, possible actions, predicted states, likelihood and expected consequence. Simulation is selective: the system first determines whether foresight is useful, then evaluates uncertainty before relying on a simulated outcome.

## 7. Imagination and counterfactual reasoning

New possibilities are developed in a bounded imagination sandbox. Candidate ideas may be explored through hypotheses, counterfactuals and simulated futures before any structural change is considered.

The existing Counterfactual Explainer remains part of the user-facing route; internal counterfactual reasoning is an extension of the same architectural philosophy, not a replacement.

## 8. Autonomous Curiosity and Innovation Reflex

The system may actively identify unknowns, contradictions, high uncertainty, missing relationships, weak matches, emerging concepts, repeated workarounds and capability gaps.

Curiosity asks: `what do I not understand?`
Innovation Reflex asks: `what can be made materially better?`

Both remain bounded by the Constitutional Genome.

## 9. Capability Genesis

The existing Capability Graph may grow through governed `Capability Genesis`:

`repeated need -> capability gap -> compose existing capabilities or propose candidate -> simulate -> verify -> govern -> register`

No AI process may directly promote a candidate into canonical authority without the required governance gate.

## 10. Experience distillation

Raw interactions should not be retained merely because they occurred. Useful lawful experience may be distilled into reusable patterns, principles, procedures, exceptions and anti-patterns, minimizing unnecessary personal detail.

## 11. Cognitive Metabolism

The cognitive system continuously digests knowledge:

`INGEST -> DIGEST -> CONNECT -> VERIFY -> DISTILL -> ABSTRACT -> CONSOLIDATE -> PURGE NOISE -> REORGANIZE`

The goal is a cleaner and more useful cognitive state, not maximum storage volume.

## 12. Fast Mind / Deep Mind

The critical user path remains fast. A fast cognitive path serves intent, retrieval, matching and explanation. Deeper consolidation, contradiction analysis, causal linking, abstraction, self-challenge and innovation work occur off the critical path when possible.

No cognitive enhancement may justify unnecessary latency in the ordinary ONE FIELD experience.

## 13. Creator, Critic, Verifier and Red Mind

Structural evolution must preserve separation of duties:

`CREATOR != CRITIC != VERIFIER != PRODUCTION AUTHORITY`

An internal adversarial review function (`Red Mind`) attempts to falsify candidate improvements, expose privacy/security failures, detect manipulation and challenge unjustified confidence.

## 14. Shadow Evolution

A candidate improvement is not live merely because it was generated. Structural candidates pass through shadow evaluation against current behavior using appropriate objectives such as relevance, safety, privacy, latency, fairness, explainability and user friction.

Required sequence:

`IMAGINE -> SIMULATE -> CRITIQUE -> VERIFY -> SHADOW -> GATE -> PROMOTE_OR_REJECT`

Direct unverified production self-modification is prohibited.

## 15. Uncertainty Ledger and Contradiction Engine

The system should explicitly track what it does not know well. High uncertainty, conflicting evidence, stale claims and weak causal links become first-class cognitive work items rather than being hidden behind invented certainty.

Contradictions may be resolved, versioned or preserved as context-dependent alternatives when both can be valid under different time, source or policy conditions.

## 16. Knowledge provenance

Important derived knowledge must retain lineage sufficient to explain where it came from, when it was learned, which evidence supported it, how it was transformed and what confidence applies.

## 17. Self-Challenge and Synthetic World Laboratory

The cognitive system may create synthetic challenges from known weaknesses and test itself in simulated environments before relying on real users to expose every failure mode. Synthetic learning remains gated by provenance, verification, security and the Constitutional Genome.

## 18. Cognitive Immune System and Memory Firewall

Not every observed input is eligible to become persistent memory. Memory admission must consider trust, provenance, anomaly, security, privacy and poisoning risk. Prompt injection, coordinated manipulation, corrupted data and adversarial memory patterns must not be promoted blindly into long-term knowledge.

## 19. Post-Handoff Blindness

At `CONTACT -> HANDOFF`:

- TIGER commercial role stops;
- external-deal observation stops;
- external negotiation learning is not authorized;
- external final-price/payment/settlement/fulfillment/completion learning is not authorized;
- internal cognitive evolution continues from lawful pre-handoff and in-platform signals.

This preserves the discovery-only / Private Discovery Rendezvous boundary while removing the obsolete implication that the entire internal learning system must stop.
