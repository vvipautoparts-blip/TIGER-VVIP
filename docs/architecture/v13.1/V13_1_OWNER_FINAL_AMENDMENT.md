# VVIP TIGER V13.1 — قرار المالك النهائي المعدِّل

**الحالة:** OWNER_FINAL_CONSTITUTIONAL_AMENDMENT

**التاريخ:** 2026-08-05

**السلطة:** يسود هذا القرار على أي نص قديم أو جزء من V13.1 يتعارض معه، ويبقى كل حكم غير متعارض من V13.1 نافذًا.

## القرارات النهائية

1. **الصور:** الحد العالمي النهائي هو **7 صور لكل إعلان**. لا يجوز زيادته بسبب قيمة الدفع، والفيديو غير مفعّل في الإصدار الحالي.
2. **الظهور:** لا يوجد رقم ظهور عالمي ثابت، بما في ذلك 250 أو 400. كمية الظهور وسعرها يحددان حصريًا داخل ختم الدولة المعتمد.
3. **الدردشة:** مسموحة بالكامل لجميع المستخدمين، ولا تحتاج موافقة المالك أو الشركاء أو منحة فردية.
4. **التوصيل:** مسموح بالكامل لجميع المستخدمين، ولا يحتاج موافقة المالك أو الشركاء أو منحة فردية.
5. **الوساطة:** مسموحة بالكامل لجميع المستخدمين، ولا تحتاج موافقة المالك أو الشركاء أو منحة فردية.
6. **التحويل إلى واتساب:** متاح لجميع المستخدمين دون أي موافقة. وظيفته الوحيدة فتح تطبيق واتساب المثبّت على جهاز المستخدم عبر رابط خارجي. المنصة لا ترسل الرسائل ولا تستقبلها ولا تقرأها ولا تخزنها ولا تدير حساب واتساب، ولا تستخدم WhatsApp API بوصفها ناقل رسائل داخل المنصة.
7. **الإلغاء:** كل قاعدة قديمة تمنع الدردشة أو التوصيل أو الوساطة، أو تعتمد 10 صور، أو تثبت 250/400 ظهور عالميًا، أو تشترط موافقات لتوفير التحويل الخارجي إلى واتساب، ملغاة ضمن نطاق هذا القرار.
8. **ضبط الإنتاج:** سياسة الوصول لا تعني الادعاء بأن كل Runtime أصبح منشورًا. تظل كل شريحة برمجية خاضعة للاختبارات والأمن وCI وخطة الرجوع قبل الدمج والإطلاق.

## قاعدة التنفيذ

يجب أن تنعكس الأحكام في عقد قابل للقراءة آليًا، واختبارات سلبية وإيجابية، ومدقق Fail-Closed، وسجل تعارض وبصمات SHA-256 تمنع رجوع أي حكم قديم بصمت.
