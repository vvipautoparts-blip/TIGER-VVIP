# V13.1 Scope Guard

هذه الدفعة تثبّت **سياسة الوصول الدستورية** وعقودها واختباراتها، ولا تدّعي أن جميع واجهات Runtime للدردشة والتوصيل والوساطة والتحويل إلى واتساب قد اكتملت أو نُشرت.

أي تنفيذ Runtime لاحق يجب أن:

- يستهلك عقد `owner_constitution.json` بدل نسخ القيم يدويًا.
- يثبت سبع صور فقط، بلا زيادة مدفوعة.
- يرفض أي رقم ظهور عالمي ثابت.
- يتيح الدردشة والتوصيل والوساطة لجميع المستخدمين بلا موافقة مالك أو شريك.
- يتيح زر واتساب لجميع المستخدمين بلا موافقات، بوصفه رابطًا خارجيًا يفتح تطبيق واتساب على جهاز المستخدم فقط.
- يمنع المنصة من إرسال رسائل واتساب أو استقبالها أو قراءتها أو تخزينها أو إدارة الحساب.
- يستخدم PR واختبارات وأدلة وخطة رجوع قبل الدمج والإطلاق.
