# V13.1 Scope Guard

هذه الدفعة لا تفعّل الدردشة أو التوصيل أو الوساطة أو واتساب أو أي دولة. هدفها تثبيت الدستور النهائي واختباره آليًا قبل لمس Runtime.

أي تنفيذ لاحق يجب أن:

- يستهلك عقد `owner_constitution.json` بدل نسخ القيم يدويًا.
- يثبت سبع صور فقط.
- يرفض أي رقم ظهور عالمي ثابت.
- يبقي واتساب الخارجي معطلًا حتى قرار تفعيل منفصل.
- يفصل السماح الدستوري عن التفعيل الإنتاجي.
- يستخدم PR واختبارات وأدلة وخطة رجوع.
