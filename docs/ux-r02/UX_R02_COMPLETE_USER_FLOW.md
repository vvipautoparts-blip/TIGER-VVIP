# UX-R02 Complete User Flow

Local entry selects only a preview user type, then continues directly to one unified Home. The user can filter and search across sectors, open listing details in place, visit public or private representations of the same identity, communicate privately when eligible, create Tiger Care requests, and inspect notifications or account status.

No step performs authentication, authorization, remote persistence, or real communication. Real identity, account state, authorization, privacy and data handling require authorized backend phases and P08 security completion.
