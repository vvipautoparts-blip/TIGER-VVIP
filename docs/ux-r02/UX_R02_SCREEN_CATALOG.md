# UX-R02 Screen Catalog

The isolated preview provides: local entry, unified home, marketplace, search and advanced search, in-place listing details, public profile, private profile, posting authorization, listing wizard, image workflow, messages, Tiger Care, notifications, settings/privacy, and safe local limit/access states.

All listing details open in an overlay in the current page context. Sectors are filters on Home, Marketplace, and Search; sector selection occurs only inside the listing wizard.
