# UX-R02 User Type Catalog

The preview contains eleven user types: viewer, standard buyer, individual seller, parts shop, maintenance center, electrical/hybrid center, general service center, dealer/distributor, company/institution, service provider, and personal VIP.

- Viewer browses only; it cannot send private messages or publish.
- Standard buyer can browse and use one-to-one communication, but cannot publish without separate authorization.
- The remaining types use the same unified home. Their account type alone never grants publishing.
- Publishing is separately previewed as Authorized, Pending approval, Not authorized, Sector mismatch, Weekly limit reached, Account suspended, Trial expired, or Missing required profile data.

CLIENT-SIDE USER JOURNEY PREVIEW IS NOT A PRODUCTION APPLICATION. AUTHENTICATION, AUTHORIZATION, DATA STORAGE, LIMITS AND SECURITY MUST BE ENFORCED BY AUTHORIZED BACKEND PHASES.
