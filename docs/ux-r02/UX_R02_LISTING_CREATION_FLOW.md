# UX-R02 Listing Creation Flow

The local wizard has eleven steps: sector, category, structured fields, title, price, city/area, description/specifications, images, review, publishing authorization, and preview result.

- Sector is required only at listing creation.
- Price must be greater than zero.
- City and area are required.
- The weekly preview limit is four listings; ad duration is 120 days.
- Publishing is a separate authorization state and is never inferred from account type.
