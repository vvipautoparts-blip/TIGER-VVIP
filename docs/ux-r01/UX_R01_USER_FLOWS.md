# UX-R01 User Flows

1. **Role preview:** choose a role and scope on the entry page or top bar; state persists for this browser session only.
2. **Scoped navigation:** select any visible sidebar route; direct unavailable routes render Access Denied.
3. **Tiger Care:** filter ticket cards, open a ticket, add a local-only note, change mock status, assign/escalate/reply through confirmation.
4. **Moderation:** open a report and confirm a local-only review action. Reporter data remains intentionally absent.
5. **Employee review:** open a scoped employee record; authorized role assigners can open the assignment drawer.
6. **Role assignment:** select a user, non-owner role, scope, optional sector/region/end date, and required reason; confirmation adds a local mock audit entry.
7. **Alerts:** mark an alert read locally or open the linked mock record.

Escalation is represented visually through Tiger Care, moderation, and assignment confirmation flows. No action reaches a backend.
