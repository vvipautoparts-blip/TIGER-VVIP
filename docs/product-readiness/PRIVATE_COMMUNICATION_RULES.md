# PRIVATE COMMUNICATION RULES

## Core Model

- Communication is strictly one-to-one only.
- No groups.
- No rooms.
- No group chat.
- No broadcast.

## Sharing And Invite Model

- Share with an existing friend is allowed.
- Request to join as a new friend is allowed.
- Session invitation limit: `20` invites per session.

## Privacy Boundary

- Communication context is private between listing owner and interacting user.
- Access to conversation metadata/content must follow role and policy boundaries.

## Platform Liability Boundary

VVIP TIGER is not a party to:

- Sale transaction
- Payment transfer
- Delivery process
- Contract execution
- Warranty obligations

The platform provides organized discovery and communication channels only.

## Safety Reminder

- Users should avoid sharing sensitive credentials.
- Report abuse or scam behavior via Tiger Care/reporting flow.
