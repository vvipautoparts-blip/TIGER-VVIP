# Account Chooser — SUPERSEDED / HISTORICAL ONLY

This former Supabase OAuth implementation specification is retired.

It is not current authentication authority, must not be used for redirects or provider configuration, and must not be used to publish or share a deployment address. VVIP TIGER now follows the federated-identity boundary in `docs/architecture/ADR-2026-08-08-federated-identity-sovereignty.md`, with authentication handled by the approved external identity runtime and VVIP retaining authorization/RLS authority.

The original material remains recoverable from Git history for audit and provenance only.
